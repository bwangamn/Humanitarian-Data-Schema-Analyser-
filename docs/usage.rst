Usage Guide
===========

Command Line Interface (CLI)
----------------------------

The primary entry point for analyzing humanitarian datasets and unifying exported
schemas is the Typer-based ``hds-analyzer`` command.

Basic Usage
~~~~~~~~~~~

Analyze a dataset file and generate an HTML report:

.. code-block:: powershell

   hds-analyzer analyze data/sample.csv --output report.html

If your virtual environment is not active, run the installed command from its
virtual-environment path:

.. code-block:: powershell

   .\humanitarian_env\Scripts\hds-analyzer.exe analyze data/sample.csv --output report.html

Command Options
~~~~~~~~~~~~~~~

.. code-block:: text

   Usage: hds-analyzer analyze [OPTIONS] FILE

   Arguments:
     FILE  Path to the dataset file (CSV, JSON, XML, Excel/XLSForm). [required]

   Options:
     -o, --output TEXT        Path to save the generated HTML report. [default: report.html]
     -s, --schema-output TEXT Optional path to export the raw JSON Schema file.
     -f, --format TEXT        Explicit format override (csv, json, xml, xlsform).
     --help                   Show this message and exit.

Exporting Raw JSON Schema
~~~~~~~~~~~~~~~~~~~~~~~~~

To generate both an HTML report and export the Draft 2020-12 JSON Schema to a file:

.. code-block:: powershell

   hds-analyzer analyze data/sample_hxl.csv -o report_hxl.html -s schema_hxl.json

Unifying JSON Schemas
~~~~~~~~~~~~~~~~~~~~~

Use ``unify`` to combine two JSON Schema Draft 2020-12 files generated by the
analyser:

.. code-block:: powershell

   hds-analyzer unify path/to/schema1.json path/to/schema2.json

The command writes the result to the current working directory as
``<schema1_stem>_<schema2_stem>_unified.json``. For example,
``drc_schema.json`` and ``mali_schema.json`` produce
``drc_schema_mali_schema_unified.json``.

Fields that appear in only one input schema are copied to the output. When a
field name and type match in both inputs, the property is retained once and its
``examples`` arrays are combined without duplicates. When matching field names
have different types, the output keeps both values as a JSON Schema type array,
such as ``["integer", "string"]``, and prints a warning. Missing files,
unreadable files, malformed JSON, and non-object JSON documents result in a
clear CLI error message and a non-zero exit code.

Programmatic Python Usage
-------------------------

You can also use the core packages programmatically in Python scripts:

.. code-block:: python

   from humanitarian_schema_analyzer.parsers.factory import ParserFactory
   from humanitarian_schema_analyzer.profiling.profiler import DataProfiler
   from humanitarian_schema_analyzer.schema.schema_builder import SchemaBuilder
   from humanitarian_schema_analyzer.reports.html_report import HTMLReportGenerator

   # 1. Parse dataset
   parser = ParserFactory.get_parser("data/sample.csv")
   parsed_dataset = parser.parse()

   # 2. Profile dataset
   profiler = DataProfiler(parsed_dataset)
   unified_schema = profiler.profile()

   # 3. Build JSON Schema
   builder = SchemaBuilder(unified_schema)
   json_schema = builder.build()

   # 4. Generate HTML Report
   generator = HTMLReportGenerator(unified_schema, json_schema)
   generator.generate("report.html")
